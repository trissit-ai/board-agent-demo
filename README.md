# 自治 Board Agent 协同看板 · Demo

一个不接任何模型、不接任何业务系统的可交互演示原型，用来说明「每块业务板一个持续存在的 Board Agent ＋ 共享专业能力池 ＋ 全局治理」这套方法论在界面上长什么样。

所有数据均为**演示虚构数据**，不构成收益承诺、行业标准或真实业务指标。

## 运行

只需要 Node.js 18 或更高版本，无第三方依赖，无需安装。

```bash
node server.js 4176
```

浏览器打开 `http://127.0.0.1:4176/`。端口可省略，默认 4173。

也可以直接用浏览器打开 `index.html`。此时进入只读模式：页面功能照常可用，但在设置面板里做的修改不会保存。

## 七个视图

| 视图 | 内容 |
|---|---|
| 概览 | 同一条事件在三层角色工作台（情报雷达、决策室、工具台）里的三种投影 |
| 业务看板 | 8 态状态机的看板，默认 6 列，可切全 8 列；每次流转都经过守卫 |
| 卡片详情 | 五组字段、运行与事件时间线、证据、验收与写回 |
| 审批与验收 | 五个人工门队列 |
| 架构与治理 | 五层参考架构、八步工作循环、L0–L4 自治等级、Agent 数量与容量公式 |
| 指标 | 流转效率、AI 工作质量、业务结果、单位经济性四维 |
| 演示控制台 | 注入事件、单步或连续推进规则引擎、编辑各类参数、导入导出配置 |

顶栏支持按事件 ID、卡片 ID、VIN、订单号检索并下钻；业务板与角色模板两个选择器联动过滤所有视图。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 单文件前端，样式与脚本全部内联，无任何外部资源 |
| `server.js` | 只负责托管页面和读写配置，仅使用 Node.js 内置模块 |
| `config.json` | 唯一的数据来源，可直接手工编辑 |

## 边界

- 不调用任何模型、不连接任何业务系统、不发起任何外部网络请求。
- 规则引擎是纯前端的确定性模拟，不产生真实的智能决策。
- 高风险动作一律停在「业务验收」等待人工处理，规则引擎不会自动完成。
- 看板保存的是协同状态，不替代 DMS、CRM、ERP、TMS、WMS 等权威业务系统。
- 背景图为 AI 生成的示意图，右下角保留生成标识。
